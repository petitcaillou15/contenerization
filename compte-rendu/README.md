# Compte rendu

Ce dossier explique **ce qui a été fait et comment**. Il est rédigé en **Markdown** (`.md`) ou en **AsciiDoc** (`.adoc`).

Chaque partie du cahier des charges a son fichier. Pour chacune : elle est soit **traitée**
(ce qui a été fait, comment, pourquoi), soit **explicitement indiquée comme non traitée**.

| Fichier | Partie |
|---|---|
| `01-images-docker.md` | Images Docker |
| `02-deploiement-kubernetes.md` | Déploiement Kubernetes |
| `03-communication.md` | Communication entre les services |
| `04-configuration.md` | Configuration |
| `05-disponibilite.md` | Disponibilité |
| `06-donnees.md` | Données |
| `07-observabilite.md` | Observabilité |
| `08-approfondissements.md` | Approfondissements (bonus) |

Le compte rendu **complète** le `README.md` : le README sert à **construire, déployer et vérifier**,
le compte rendu sert à **expliquer et justifier**.
