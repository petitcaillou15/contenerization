== À vous de jouer !

=== Objectif de la séance

Obtenir une *première version complète* de l'application fonctionnant sur Kubernetes, avec *tout ce qu'il faut* pour réaliser le *socle obligatoire*.

=== Ce qu'il y a à faire en séance 2

. Déployer *tous* les microservices
. Créer les *Services* et configurer les communications entre composants (par *nom*, pas par IP)
. Externaliser la configuration avec des *ConfigMaps*
. Gérer les mots de passe et clés avec des *Secrets*
. Connecter l'application à la *base de données externe*
. *Exposer* l'application hors du cluster
. Mettre en place des *probes* (liveness, readiness, startup si utile)
. Tester : supprimez des Pods, vérifiez que tout se recrée
. *Versionner* vos images (tag explicite) : la *même image* quelle que soit la configuration
. Travail libre sur le projet

=== Vérifiez votre travail

* [ ] Tous les composants sont `Running` et `Ready`
* [ ] Les services communiquent par *nom*
* [ ] Aucun mot de passe dans une image ni en clair dans le dépôt
* [ ] L'application est accessible depuis votre navigateur
* [ ] La base de données est atteinte, les données persistent
* [ ] La suppression d'un Pod n'interrompt pas l'application
* [ ] Vous pouvez *afficher les logs* d'un composant

=== Aide-mémoire

[source,bash]
----
kubectl get all -n <namespace>
kubectl get svc,endpoints -n <namespace>
kubectl describe pod <nom> -n <namespace>
kubectl logs <pod> -n <namespace>
kubectl rollout restart deployment/<nom> -n <namespace>
kubectl run test --rm -it --image=busybox -n <namespace> -- sh
minikube addons enable ingress
----

=== Le test qui valide tout le reste

Supprimez votre Namespace, *entièrement* :

[source,bash]
----
kubectl delete namespace <votre-namespace>
----

Puis *remontez toute l'application*, uniquement à partir de votre dépôt.

* Chaque étape doit être *décrite dans le README* ou *scriptée*
* Si vous devez improviser une commande, votre README est *incomplet*
* C'est exactement ce qui est évalué sur la *reproductibilité*

*Faites ce test avant lundi* — pas pendant la séance 3.
